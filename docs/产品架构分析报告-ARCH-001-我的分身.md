## 五、问题诊断与优化建议

### 5.1 问题清单

#### 问题一：页面数量过多，结构混乱 ⛔

```
┌────────────────────────────────────────────────────────────────────┐
│ 问题描述                                                          │
├────────────────────────────────────────────────────────────────────┤
│ • 总页面数：约 70+ 个                                              │
│ • 部分页面职责重叠                                                 │
│ • 页面命名不规范                                                   │
│ • 层级深度过深（最深5级）                                          │
└────────────────────────────────────────────────────────────────────┘
```

**影响**：
- 用户难以找到功能
- 代码维护成本高
- 导航体验差

**优化建议**：
1. 按功能模块重组页面目录
2. 合并职责重叠的页面
3. 规范页面命名（统一小写+中划线）
4. 控制导航深度≤3级

---

```
┌────────────────────────────────────────────────────────────────────┐
│ 问题：社交广场 (pages/social/index) 同时承载                         │
```

#### 问题三：状态管理分散 ⛔

```
┌────────────────────────────────────────────────────────────────────┐
│ 问题：状态管理分散在多处                                            │
├────────────────────────────────────────────────────────────────────┤
│                                                                    │
│  当前状态：                                                         │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐              │
│  │ userStore    │  │ avatarStore  │  │ chatStore    │              │
│  │  (用户信息)   │  │  (分身状态)   │  │  (聊天状态)   │              │
│  └──────────────┘  └──────────────┘  └──────────────┘              │
│                                                                    │
│  问题：                                                             │
│  • 部分页面使用 localStorage 自行管理                               │
│  • 状态同步逻辑缺失                                                 │
│  • 缺少全局状态更新机制                                             │
│                                                                    │
└────────────────────────────────────────────────────────────────────┘
```

**优化建议**：
1. 建立统一的状态同步机制
2. 使用 Taro 事件总线管理跨页面状态
3. 添加状态持久化中间件
