# Morena 一页纸（产品 × 技术 × 运营 × 融资）

## 一句话定义

- “AI 分身 × 发布订单”的双边平台：需求侧发单（内容生产+多平台发布+验收），供给侧用分身接单履约（生成内容/发布回填证据/结算收益），平台以订阅+抽成+增值服务变现。

## 目标用户与场景（运营投放口径）

- 需求侧：中小商家/内容团队/个人创作者，需要“低成本、可验收、可规模化”的内容生产与多平台分发
- 供给侧：具备内容生产能力的个人/工作室，或运营托管的分身供给
- 典型场景：活动投放、日更/矩阵号运营、商品种草、短视频分发、品牌号运营外包

## 北极星指标

- 每周“完成验收订单数”与“完成验收 GMV”（Completed Orders / Completed GMV）

## 核心飞轮

- 订单需求 → 分身供给履约 → 发布证据回填 → 验收与评分 → 推荐/定价与复购 → 供给升级（技能/模板/订阅）

## 商业化主线

- 订阅（能力解锁） + 抽成（订单成交） + 增值（质检/优先派单/模板包/账号能力）

## 产品路线图（12 个月）

|---|---|---|---|---|
| Phase 0（0-4周）稳定&数据化 | 能跑起来、能用数据说话 | 1) 漏斗与埋点最小集（注册/创建分身/发单/接单/反馈/验收/订阅） 2) 统一平台与发布状态口径（canonical key + 发布状态机）3) 支付/订单关键链路可观测 | 冷启动供给陪跑（分身模板+培训）；需求侧用订单模板拉起首批成交 | 每周输出增长&履约周报；关键漏斗可追踪；验收完成订单开始稳定产生 |
| Phase 1（1-3个月）流动性&质量体系 | 订单规模起来、质量可控 | 1) 分身能力分层（新手/熟练/专家）+ 评级体系 2) 订单模板化（平台/内容类型/证据要求）3) 争议/退款/仲裁流程（先流程后自动化）4) 派单推荐按履约数据升级 | 供给运营岗位化：招募/排班/质检；需求运营岗位化：垂类模板/复购 | 完成率、一次通过率、交付时长显著改善；复购出现；争议率可控 |

| Phase 3（6-12个月）平台化&护城河 | 从项目到公司：可扩展、可复制 | 1) 技能/模板市场化（供给资产沉淀）2) 机构/B2B 能力（团队协作/批量发单/审计）3) 合规与风控体系（内容/账号/证据链审计） | 渠道与行业化复制：形成 SOP 与可复用打法 | 形成壁垒叙事：履约数据→推荐/定价；供给资产→交付效率；合规风控→规模化门槛 |

## 技术路线（CTO对外口径）

- 主链与模型：订单驱动发布闭环（confirm/publish/feedback/accept）、多平台 canonical key、证据链与可审计状态机
- 稳定性与可观测性：关键接口耗时/错误率、异步任务状态、支付回调成功率、订单状态一致性
- 数据治理：统一指标口径（增长/履约/财务），对账规则先行；明确单一事实源与后续迁移策略
- 合规风控：内容审核、账号风险、证据链审计、争议与退款闭环

## 运营作战（0-90 天最小打法）

- 供给冷启动：分身模板 + 招募培训 + 排班托管 + 抽检质检（目标：完成率/一次通过率先上来）
- 需求冷启动：垂类订单模板 + 交付物标准化 + “可验收”话术（目标：首单→复购）
- 增长机制：邀请裂变 + 渠道投放 + 每两周实验复盘（只看假设→指标→结论）

## 融资一页叙事（给融资团队直接复用）

- 现在的问题：内容生产与多平台分发高频刚需，但人工履约成本高、质量不稳、难规模化
- 我们的解法：AI 分身把履约变成可复制供给；订单-证据-验收把交付结果数据化
- 壁垒来源：履约数据→推荐/定价；供给资产（技能/模板）沉淀；证据链审计与风控体系
- 资金用途（建议口径）：供给运营与质检体系、增长获客、模型与工程稳定性、合规与风控

- 需求：新增发单用户、付费发单转化、复购率、AOV
- 供给：活跃分身数、接单率、完成率、一次通过率、平均交付时长、争议/退款率
- 商业化：订阅转化率、ARPPU、Take Rate、毛利（扣模型/算力/质检/补贴）
