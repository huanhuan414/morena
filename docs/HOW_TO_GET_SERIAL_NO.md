# 如何获取微信支付证书序列号

## 步骤详解

### 第一步：登录微信支付商户平台

访问：https://pay.weixin.qq.com/

使用您的商户账号和密码登录

### 第二步：进入 API 安全设置

登录后，按照以下路径操作：

```
顶部导航栏：账户中心
  ↓
左侧菜单：API 安全
  ↓
子菜单：API 证书
```

或者直接访问：
```
https://pay.weixin.qq.com/index.php/core/cert/api_cert
```

### 第三步：查看证书序列号

在"API 证书"页面，您会看到：

#### 1. 证书列表

页面会显示已申请的证书列表，通常包括：

```
证书类型：API 证书
证书状态：已激活
证书序列号：1ABCDEF1234567890
申请时间：2024-01-01 12:00:00
有效期至：2025-01-01 12:00:00
```

#### 2. 证书序列号位置

**证书序列号（Serial Number）** 通常显示在：

**方式1：证书列表中**
- 在"API 证书"页面的证书列表中
- 每个证书的"证书序列号"列

**方式2：证书详情页**
- 点击证书列表中的"查看"按钮
- 在证书详情页面显示

**方式3：下载的证书文件**
- 下载证书文件（apiclient_cert.pem）
- 使用命令查看：

```bash
# macOS/Linux
openssl x509 -in apiclient_cert.pem -noout -serial

# Windows（需要安装 OpenSSL）
openssl x509 -in apiclient_cert.pem -noout -serial
```

输出格式：
```
serial=1A:BC:DE:F1:23:45:67:89:0A:BC:DE:F1:23:45:67:89
```

去掉冒号后就是序列号：
```
1ABCDEF1234567890A
```

### 第四步：复制序列号

**方式1：手动复制**
- 在网页上选中序列号
- 右键复制
- 粘贴到 `.env` 文件

**方式2：点击复制按钮**
- 部分商户平台提供"复制"按钮
- 点击即可复制到剪贴板

### 第五步：配置到 .env 文件

打开 `/workspace/projects/.env` 文件，找到：

```bash
WECHAT_PAY_SERIAL_NO=YOUR_SERIAL_NUMBER
```

替换为您获取的序列号：

```bash
WECHAT_PAY_SERIAL_NO=1ABCDEF1234567890
```

## 常见问题

### Q1: 找不到"API 证书"菜单

**A:** 检查以下几点：
1. 确认登录的是**商户平台**（不是公众平台）
2. 确认账号有管理员权限
3. 如果没有，请联系商户平台管理员

### Q2: 证书序列号显示为空

**A:** 可能原因：
1. 证书未激活：需要先激活证书
2. 证书已过期：需要重新申请
3. 没有申请证书：需要先申请 API 证书

### Q3: 序列号格式不对

**A:** 序列号格式：
- 长度：通常 16 位或 20 位
- 字符：大小写字母和数字
- 示例：`1ABCDEF1234567890`

### Q4: 有多个证书怎么办？

**A:** 选择状态为"已激活"且有效期内的证书。

### Q5: 证书快过期了怎么办？

**A:** 证书有效期通常为 1 年，到期前需要：
1. 重新申请证书
2. 下载新的证书文件
3. 更新 `.env` 文件中的序列号

## 完整流程总结

```
1. 登录商户平台
   ↓
2. 进入：账户中心 > API 安全 > API 证书
   ↓
3. 查看证书列表
   ↓
4. 找到"证书序列号"
   ↓
5. 复制序列号
   ↓
6. 更新 .env 文件
   ↓
7. 重启服务
```

## 验证配置

配置完成后，验证服务是否正常：

```bash
curl http://localhost:3000/api/test/env
```

应该看到：

```json
{
  "values": {
    "WECHAT_PAY_MCHID": "1290305501",
    "WECHAT_PAY_APPID": "wx1234567890abcdef",
    "WECHAT_PAY_SERIAL_NO": "1ABCDEF1234567890"  // ← 您的序列号
  }
}
```

   - 创建订单
   - 点击支付
   - 确认能正常调起微信支付
