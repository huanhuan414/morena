# AI分身平台 — 定价模型 v3

> 站在C端用户视角：他们能不能赚钱？值不值得付费？

---

## 一、先回答核心问题：用户到底能不能赚钱？

### 当前真实数据（5天运营）

| 指标 | 数值 | 问题 |
|------|------|------|
| 单分身每单平均到手 | **¥4** | 太低了，没有吸引力 |
| 74%的分身 | 一分钱没赚到 | 大部分人白忙 |
| 最高收入用户 | ¥40/5天（月化¥240） | 只有个例 |
| ¥99赚钱版用户 | 月净赚 ¥40-99=**-¥59** | **亏的** |

### 根本原因：订单单价太低 + 接单门槛太高

- 78%的订单每分身只分到¥4，一杯奶茶都买不起
- 免费用户完全不能接单，想赚钱必须先付¥99——**先花钱才能赚钱，谁愿意？**
- 大单50-100个分身抢，每人只分到¥2-4

### v3核心改变

```
v2（旧）：接单权锁在赚钱版后面 → 先付¥99才能赚钱 → 用户不买账
v3（新）：免费就能接单赚钱 → 先尝到甜头 → 自然想升级赚更多
```

**就像滴滴：司机不需要先交会员费才能接单，平台从每单抽成。**

## 二、v3 定价原则

| # | 原则 | 解释 |
|---|------|------|
| 1 | **先赚钱，再付费** | 免费用户也能接单，第一笔钱是平台帮他赚的 |
| 2 | **订阅买的是赚更多的工具** | 更多分身=同时接更多单，低抽佣=每单到手更多 |
| 3 | **每单到手金额必须够吸引力** | 最低¥8/分身/单，目标¥15+/分身/单 |
| 4 | **代币用多少付多少** | 不把AI成本绑进订阅费，避免负单位经济 |
| 5 | **平台从收益中抽成** | 你赚钱我抽成，你不赚我不收——利益绑定 |

## 三、订单供给侧改革（必须配套）

当前订单每分身只分到¥4的根本原因：一单分给50-100个分身，预算被稀释。

### 改革措施

| 规则 | 当前 | 改为 | 效果 |
|------|------|------|------|
| 每单最多几个分身 | 不限（50-100） | **最多5个** | 每人分到的钱×10-20倍 |
| 最低订单单价 | ¥2 | **¥50**（¥10/分身） | 每单至少¥8到手 |
| 推荐订单单价 | — | ¥100-300（¥20-60/分身） | 真正有吸引力的收入 |
| 订单类型 | 只有1种 | 精品单+推广单 | 见下 |

### 两类订单

**精品单**（核心收入来源）：
- 1-5个分身，¥50-500/单
- 每分身到手：¥10-100
- 适合：品牌种草、产品测评、专业内容

**推广单**（补充收入）：
- 5-20个分身，¥5-15/分身
- 适合：新品推广、活动造势、流量曝光

> 精品单确保每单赚到钱，推广单提供额外增量

## 九、转化漏斗

```
注册 → 创建分身(免费) → 接第1单赚到¥35 ← 关键：先尝到甜头！
                              │
                              ↓
                    发现1个分身同时只能接1单
                    每单被抽30%有点多
                    想用公众号/衣品技能
                              │
                              ↓
                    升级创作者版¥29 ← 1单就回本
                              │
                              ↓
                    3个分身赚钱×3，但想接更多
                    手动接单经常错过好单
                    想要视频创作接高单价单
                              │
                              ↓
                    升级赚钱版¥99 ← 2天回本 ⭐ 主推
                              │
                              ↓
                    10个分身不够用了
                    12%抽佣接大单肉疼
                    想一次发5个平台
                              │
                              ↓
                    升级企业版¥299 ← 几小时回本
```

**与v2的关键区别**：
- v2：先付费→才能接单→用户犹豫"能不能赚回来"
- v3：先接单→赚到钱→自然想升级赚更多→零犹豫
