# 独立商品购物分包接入说明

## 1. 复制目录

将整个 `mini_shop` 文件夹复制到现有原生微信小程序项目根目录。

## 2. 注册独立分包

把 `app-json-fragment.json` 中的对象追加到根目录 `app.json` 的 `subpackages` 数组，不要覆盖现有分包配置。

示例：

```json
{
  "pages": ["pages/index/index"],
  "subpackages": [
    {
      "root": "mini_shop",
      "independent": true,
      "pages": [
        "pages/product/index",
        "pages/success/index",
        "pages/order-query/index"
      ]
    }
  ]
}
```

## 3. API 地址

正式环境默认请求：

```text
https://shop.51webjs.com/api/mini-shop
```

如需更换域名，只修改 `mini_shop/config.js`。

## 4. 微信后台域名

- request 合法域名：`https://shop.51webjs.com`
- downloadFile 合法域名：`https://voic.51webjs.com`

服务器 `.env` 需要配置：

```text
WECHAT_MINI_APP_ID=小程序AppID
WECHAT_MINI_APP_SECRET=小程序AppSecret
WECHAT_MINI_ENV_VERSION=release
WECHAT_MINI_CHECK_PATH=1
```

体验版联调时可临时使用：

```text
WECHAT_MINI_ENV_VERSION=trial
WECHAT_MINI_CHECK_PATH=0
```

## 5. 开发工具调试

开发工具编译模式选择：

```text
mini_shop/pages/product/index
```

启动参数可使用：

```text
public_code=商品 public_code
```

正式商品码通过 `scene` 传入同一个 public_code。

## 6. 说明

- 本分包不依赖主包的 app.js、app.wxss、公共组件或登录状态。
- `mini_shop/app.js` 是独立分包自己的最小入口，请勿删除，也不要引入主包初始化代码。
- 不需要修改现有 tabBar 和现有业务页面。
- 当前交易流程已接入微信小程序支付：下单后调用 `wx.requestPayment`，支付成功回调后订单自动进入待发货。
- 页面未加入主小程序导航，用户通过商品小程序码进入。
