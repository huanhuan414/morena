> **报告日期**：2026年6月  
> **事件日期**：2026年6月10日  
> **报告性质**：平台安全事件技术调查报告  
> **严重等级**：高危  

---

## 一、事件概述

2026年6月10日，莫瑞娜平台推荐拉新系统遭到专业刷量团伙规模化攻击。该团伙利用自动化脚本批量调用微信小程序登录接口，伪造设备指纹注册虚假账号，通过推荐码绑定机制大规模套取平台 coin 奖励。

**关键数据：**

| 指标 | 数值 |
|------|------|
| 虚假注册账号 | 5,347 个 |
| 非法发放 coin | 75,240 枚 |
| 获利推荐人数 | 155 人 |
| 被推荐人付费转化 | **0 人** |
| 平台经济损失估算 | 约 ¥7,524 元（按 100 coin = ¥10 计） |
| 虚假账号占平台总用户比 | 85.7%（5,887 / 6,861） |

---

## 二、刷量方式还原

### 攻击路径

```
注册种子账号（获取推荐码）
        ↓
自动化脚本调用 wx.login() 获取真实 code
        ↓
调用后端 /api/auth/wx-login 接口自动注册
        ↓
伪造不同 device_id 绑定推荐人 ID
        ↓
推荐人即时获得 14 coin/人 奖励
        ↓
每个推荐人精确触达 50人/天 上限后切换下一账号
```

### 技术手段

1. **微信自动化登录**：利用群控或模拟器批量调用 `wx.login()`，获取真实 `code` 后调用后端接口自动注册。所有虚假账号的 `openid` 前缀 100% 为 `onHLK4`（同一微信开放平台）
2. **设备指纹伪造**：5,347 个被推荐账号拥有 5,347 个不同的 `device_id`（唯一率 100%），但同一设备型号同一分钟内注册高达 21 人，明显为脚本批量生成
3. **推荐码自动绑定**：每个新注册账号自动填充推荐人的 `referred_by` 字段
4. **IP 分散**：使用不同 IP 地址操作，但仍有同一 IP 操控 5-8 个推荐人账号的情况

## 五、代码漏洞分析

### 漏洞1：注册接口无限流

**文件**：`auth.controller.js`

```javascript
// 当前代码 - 无 @Throttle 装饰器
@Post('wx-login')
async wxLogin(@Body() body: WxLoginDto) { ... }
```

**问题**：注册接口没有任何频率限制，脚本可以在短时间内无限次调用。全局 `main.js` 也未配置 rate-limit Guard。

### 漏洞2：推荐上限过高且奖励即时发放

**文件**：`referral.service.js`

```javascript
checkDailyInviteLimit = 50  // 每日邀请上限 50 人
// 每成功邀请 1 人奖励 14 coin，即时发放无审核
```

**问题**：
- 每日 50 人上限对刷量团伙来说远不够限制（50人 × 14 coin = 700 coin/天/账号）
- 奖励即时发放，无需审核或延迟，刷量后立即获利
- 多账号操作可绕过单账号上限

### 漏洞3：风控规则为空

**文件**：`referral.service.js`

`checkRiskControl` 函数存在但 `referral_risk_controls` 表中规则为 0 条。该函数从未拦截过任何异常推荐行为。

**应有但缺失的风控规则**：
- 同一 IP 下多个推荐人账号聚集检测
- 被推荐人注册时间与推荐人注册时间关联分析
- 被推荐人行为检测（注册后无任何操作即判定为空壳）
- 推荐人每日拉新速度异常检测
- 同设备型号大量注册检测

### 漏洞4：注册无需验证码

注册接口仅依赖微信 `code` 换取 `openid`，无图形验证码、短信验证码等人机验证。自动化脚本可以批量调用 `wx.login()` 获取 `code` 后直接注册。

### 漏洞5：device_id 可伪造

客户端传递的 `device_id` 未做服务端校验，脚本可以随意生成不同格式的设备指纹，绕过设备去重检测。

   - 同一 IP 推荐人聚集检测（阈值：同 IP ≤ 2 个推荐人）
   - 被推荐人注册间隔检测（阈值：注册后 5 分钟内拉人需审核）
   - 被推荐人行为检测（阈值：24 小时内无操作则扣回奖励）

## 八、结论

本次事件是一起 **有组织的专业刷量攻击**，攻击者具备以下特征：

1. **专业团伙**：昵称"小齐（接APP推广小程序拉新等）"、"迪窄电子商务"等明确表明身份为专业推广/刷量从业者
2. **技术手段**：使用自动化脚本批量调用微信登录接口，伪造设备指纹，模拟正常注册流程
3. **组织化操作**：同一 IP 操控 5-8 个推荐人账号，每个账号精确触达每日 50 人上限
4. **零真实行为**：5,347 个被推荐账号无任何真实使用行为（0付费、0订阅、0会话）
5. **纯套利目的**：刷量者获取 coin 后 100% 未消费，等待变现

**判定结论**：6月10日新增的 5,347 名被推荐用户中，**至少 5,300 个为刷量产生的虚假账号**（按 0 付费转化、0 会话产生判定），占当日注册总量的 **90.2%**。155 名推荐人中，**至少 110 人为刷量从业者**（按拉新数 ≥ 10 且被推荐人 0 付费判定），合计非法获取 **74,940 coin**（约 ¥7,494 元等值）。
